# How to Open This Repository in VS Code

GitHub opens files in the browser by default. That is normal.

To open this repository properly in VS Code, clone it first.

---

## Method 1: Clone and Open

```bash
git clone https://github.com/jarjishkhan695-blip/MY_SQL_JOURNEY.git
cd MY_SQL_JOURNEY
code .
```

---

## Method 2: Open the Workspace File

```bash
code sql_journey.code-workspace
```

---

## Method 3: Browser-Based VS Code

Open the repository on GitHub and press:

```text
.
```

This opens the repository in `github.dev`.

---

## Important

For running SQL queries, you still need a database system like MySQL, PostgreSQL, SQLite, or another SQL database. VS Code only edits the files. It does not automatically run SQL unless you install and configure a database extension.
