# My SQL Journey

This repository documents my SQL learning journey in a structured way.

Instead of adding random SQL files, this repository is divided into clear learning sections:

1. **SQL Basics**
2. **Filtering and Sorting**
3. **Aggregate Functions and Grouping**
4. **Joins and Relationships**
5. **Subqueries and CTEs**
6. **SQL Functions**
7. **Advanced SQL Concepts**
8. **Practice Questions**

The goal is to learn SQL from basic commands to real query-writing skills used in databases, analytics, and backend development.

## Database Used

Most files use MySQL-style SQL because MySQL Workbench is beginner-friendly and commonly used.

Some SQL concepts are standard and work similarly in other databases like PostgreSQL, SQLite, SQL Server, and Oracle, but syntax can differ slightly.

## Learning Path

Follow this order:

```text
Basics → Filtering → Aggregation → Joins → Subqueries → Functions → Advanced SQL → Practice
```

Do not jump directly to joins or window functions if your basics are weak. SQL looks easy at first, but real skill comes from writing clean queries repeatedly.
